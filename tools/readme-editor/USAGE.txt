EDITING
Open http://127.0.0.1:8774/tools/readme-editor/ in Edge.
Change project names, descriptions, tools, links and screenshot files.
Choose whether screenshots fill their frame or show their whole image.
The browser saves drafts locally using IndexedDB; download project data as a backup.
Open an exported combined SVG or JSON to restore all three project panels.
Open a single project SVG to replace only its matching panel in the current draft.
Open a résumé SVG to restore résumé labels/links without replacing project images.
Download the asset bundle after editing; it includes your current artwork,
project-data.json, embed code and the three current PDF files.

DIRECT SVG EDITING
Names, descriptions, labels and tools remain native <text> elements.
Screenshots use embedded <image href="data:image/png;base64,..."> elements.
Layer groups: project-1 / project-2 / project-3, pcb-background.
The Cormorant font is embedded so it does not need a remote font request.
The SVG can be opened in a text editor or vector editor. Some editors may
require installing Cormorant Garamond to display the embedded font correctly.
The browser editor imports its metadata, not arbitrary direct text edits.
After manual XML edits, update the matching metadata or use the file directly.

README LINKS
A README embeds SVG as an image. Links inside that image are not interactive.
Use separate project SVGs wrapped in Markdown/HTML links for three destinations.
The embed-code panel generates these wrappers; PHASE and Vestigium stay unlinked and are labelled Private.
Place SVGs in assets/ and PDFs in resumes/ beside your README.
For this profile, the selected resume shape is notched.
The bundled PDFs reflect the current local copies. Updating a PDF requires
replacing the file itself; editing a button changes only its label and link.

ANIMATION
Six low-opacity PCB traces animate via CSS stroke-dashoffset.
No JavaScript, animated filters, external images or external fonts inside SVGs.
Reduced-motion preference stops the signal animation. Still SVG also included.
Tested locally in Edge as images with JavaScript disabled, not live on GitHub.
